# Pectra Validator Optimizer

A staking strategy simulator purpose-built for Ethereum’s upcoming **Pectra upgrade**.

This tool helps treasury teams and institutional stakers:
- Model validator growth under the 2048 ETH cap
- Compare strategies like Set-and-Forget vs Active Treasury
- Calculate uplift vs legacy 32-ETH compounding
- Visualize staking rewards over time

## 🌐 Live Features

- ✅ Dynamic inputs (ETH, APR, Time Horizon)
- ✅ Optimized validator composition (auto-compounding)
- ✅ Comparison table vs legacy strategy
- ✅ Visual reward chart
- ✅ Active strategy card (only shown when it beats passive)
- 🎨 Styled using Pier Two’s official branding

## 🧱 Stack

- Next.js (App Router)
- React
- Tailwind CSS
